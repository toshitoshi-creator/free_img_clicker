# 素材ガチャクリッカー

タップでポイントを貯めてカプセルを引き、フリー素材（食べ物・動物・家具・食器・植物・乗り物・建物・自然・ファッション・道具・あそび・絵画）を集めるクリッカーゲーム。
ビルド不要。`index.html` をスマホのブラウザで開けば動きます（将来 Capacitor などでアプリ化予定）。

## ファイル構成
- `index.html` … 画面
- `style.css` … 見た目
- `config.js` … バランス調整用の数値（排出率・倍率・自動クリック）
- `items.js` … 素材データ（全913種：N329 / R288 / SR127 / SR+86 / UR83、12ジャンル。攻撃・防御つき）。`tools/build-assets.js` で自動生成
- `images/n` ドット絵 PNG、`images/r` イラスト（SVG・WebP）、`images/sr` 写真（SR 240px・UR 320px JPEG）
- `tools/asset-list.js` … N・R の素材一覧、`tools/photo-list.json` … SR・SR+・UR の写真と絵画の一覧（`rank` に `'SR+'` / `'UR'`、省略で SR）、`tools/gld_fetch.py` … Google Landmarks の画像を1枚ずつ取得（ここを編集して作り直す）
- `LICENSES.md` … 素材のクレジットとライセンス
- `game.js` … ゲームロジック

## 画面（スマホアプリ専用・縦画面）
- 上：ポイント／クリック合計／倍率／図鑑のステータスバー（大きい数は 万・億・兆 で短く表示）
- ガチャ：中央に出てきたカード、親指の届く下部に大きなタップボタン（指を置いた瞬間に反応・連打/複数指OK、+ポイントが浮かぶ）
- 図鑑：ランクタブ＋ジャンルチップで絞り込み。「ランク×ジャンル」（例：N・動物）ごとに見出しと n/m を表示。新規入手があるとタブバーに赤丸
- メニュー：あそびかた・記録・クレジット・リセット
- 下：タブバー（ガチャ／図鑑／メニュー）。ノッチ・ホームバーの safe-area に対応
- PC・横向きは想定しない（アプリ化時は縦画面固定にする）

## 仕様
- **素材**：すべて実在のフリー素材（詳しくは LICENSES.md）
  - N ドット絵：Streamline Pixel（CC BY 4.0）・pixelarticons（MIT）を色付けしたもの、Twemoji（CC BY 4.0）を18マスにドット化したもの
  - R イラスト：Twemoji（CC BY 4.0）・Microsoft Fluent Emoji 3D（MIT）
  - UR 名所・名画：有名な建物＝Google Landmarks Dataset v2（Wikimedia Commons の写真。CC BY / CC0 など写真ごと）、有名な乗り物＝国立航空宇宙博物館（CC0）、絵画＝広重・北斎・レンブラント・ゴッホなど（Cooper Hewitt・スミソニアン・アメリカ美術館、CC0）
  - SR+ 人気・貴重：SR の写真のうち人気の動物（パンダ・ライオンなど）、人気の乗り物（スポーツカー・こうそくれっしゃなど）、貴重品（銀器・アンティークの時計や椅子）。カードは金と赤
  - SR 写真：Smithsonian Open Access（CC0。動物＝国立動物園、家具・食器＝クーパー・ヒューイット、飛行機・宇宙船＝国立航空宇宙博物館）、Fruits-360（MIT。果物・野菜）、Open Images Dataset（CC BY 2.0。植物・乗り物。写真ごとに撮影者を表記）
- **ランク**：N＝ドット絵、R＝イラスト、SR＝写真、SR+＝人気・貴重な写真、UR＝有名な建物・乗り物・名画。排出率 58/27/8/5/2%。種類数は N＞R＞SR＞SR+＞UR
- **ポイント**：1タップで「倍率」分のポイント。カプセル1個の値段は `4 × (引いた回数+1)^1.8 × 1.0002^引いた回数`（目安：5タップ/秒で自動クリック解放まで約3分、全913種コンプまで約1時間）
- **倍率**：`(1 + N種類数×0.5) × (1 + R種類数×0.1) × (1 + SR種類数×0.1) × (1 + SR+種類数×0.05) × (1 + UR種類数×0.3)` × コンプボーナス を切り捨て
- **ジャンル別コンプボーナス**：「ランク×ジャンル」（約40区分）を全種そろえるごとに倍率×1.03（`GENRE_BONUS`）
- **ランク別コンプボーナス**：N を全種そろえると倍率×2、R は×2、SR は×2、SR+ は×3、UR は×4
- **自動クリック**：新規カード（種類数）が20種に達したら解放。間隔は 1000ms から、1種増えるごとに ×0.9（最短50ms）
  - 自動クリックにも倍率が乗る。タップ数には数えない
- **攻撃・防御**（今後の対戦機能用）：各カードに攻撃・防御（それぞれ1〜20）。合計は N 6〜15、R 14〜25、SR 22〜30、SR+ 31〜35、UR 36〜40 でランクが高いほど強い。攻撃の上限は N 10・R 15・SR 20・SR+ 18・UR 20（`ATK_MAX`）
  - `tools/build-assets.js` が ID から決まった値を自動で割り振る（毎回同じ）。動物・乗り物・あそびは攻め寄り、植物・家具・建物は守り寄り
  - `tools/asset-list.js` / `photo-list.json` の行に `atk` と `def` を書けば手動で決められる（範囲外はビルドでエラー）
  - カードの名前の下に「攻○ 防○」、図鑑の詳細に攻撃・防御・合計を表示
- **クリック合計**：これまでのクリック（タップ＋自動クリック）で稼いだポイントの合計。ステータスバーに常に表示、内訳はメニューの記録に
- **全種コンプ記録**：最初のタップからコンプまでの時間・タップ数・回数を表示
- **図鑑の詳細**：入手済みカードを押すと拡大表示＋所持数・素材の出典
- **クレジット画面**：素材の配布元ごとに作者・ライセンス・改変内容・該当素材を一覧
- **セーブ**：localStorage（キー `sozai-gacha-v3`。素材の種類数が変わると全種コンプ記録は取り直し）

## 素材の入れ替え・追加
1. 素材の npm パッケージを取得して展開（`npm pack <名前>` → `tar xzf`。展開先のフォルダ名は `tools/build-assets.js` 冒頭を参照）
2. `tools/asset-list.js`（N・R）または `tools/photo-list.json`（SR 写真）に行を足す
   - N は `icon` と `fill`（Streamline/pixelarticons）か `src: 'twp'` と絵文字の `code`（Twemoji をドット化）、R は絵文字の `code`、SR は Smithsonian の画像ID・Open Images の ImageID（`media`）か Fruits-360 のフォルダ名
3. 写真を変えたら `python3 tools/build-photos.py <キャッシュ> <Fruits-360のclone>`（Fruits-360 は `git clone --filter=blob:none --no-checkout` で十分）
4. `node tools/build-assets.js <展開したディレクトリ>` で `items.js` と `images/` を作り直す（名前・ID の重複はエラーになる）
5. 新しい配布元を使ったら `CREDIT` と LICENSES.md にも追記する

Kenney（kenney.nl、CC0）の素材も使える。zip をダウンロードして `images/` に置き、`items.js` の該当アイテムに `img` と `credit` を書けばよい（CC0 なので表記は任意だが、クレジットには載せる）
