# 素材ガチャクリッカー

タップでポイントを貯めてカプセルを引き、フリー素材（食べ物・動物・家具）を集めるクリッカーゲーム。
ビルド不要。`index.html` をブラウザで開けば動きます。

## ファイル構成
- `index.html` … 画面
- `style.css` … 見た目
- `config.js` … バランス調整用の数値（排出率・倍率・自動クリック）
- `items.js` … 素材データ（全36種：N18 / R12 / SR6）
- `game.js` … ゲームロジック

## 画面（スマホ縦画面ファースト）
- 上：ポイント／倍率／図鑑のステータスバー
- ガチャ：中央に出てきたカード、親指の届く下部に大きなタップボタン（指を置いた瞬間に反応・連打/複数指OK、+ポイントが浮かぶ）
- 図鑑：3列グリッド、ランクタブは横スクロール。新規入手があるとタブバーに赤丸
- メニュー：あそびかた・記録・クレジット・リセット
- 下：タブバー（ガチャ／図鑑／メニュー）。ノッチ・ホームバーの safe-area に対応
- 横向きはカードとボタンを左右に並べる。PCでは中央にスマホ幅（最大480px）で表示

## 仕様
- **ランク**：N＝ドット絵、R＝手描き風・イラスト、SR＝写真。排出率 70/25/5%
- **ポイント**：1タップで「倍率」分のポイント。カプセル1個の値段は `10 × (引いた回数+1)^1.5`（目安：自動クリック解放まで約1〜4分、コンプまで約10分〜1.5時間）
- **倍率**：`(1 + N種類数×1) × (1 + R種類数×0.25) × (1 + SR種類数×2)` を切り捨て
  - 最初の1枚で2倍
- **ランク別コンプボーナス**：N を全種そろえると倍率×2、R は×3、SR は×5（掛け算。全種コンプで 988×30＝29,640倍）
- **自動クリック**：新規カード（種類数）が20種に達したら解放。間隔は 1000ms から、1種増えるごとに ×0.9（最短50ms）
  - 自動クリックにも倍率が乗る。タップ数には数えない
- **全種コンプ記録**：最初のタップからコンプまでの時間・タップ数・回数を表示
- **図鑑の詳細**：入手済みカードを押すと拡大表示＋所持数・素材の出典
- **クレジット画面**：`credit` を持つ素材の一覧（今は全36種オリジナル描き下ろしなので外部素材なし）
- **セーブ**：localStorage（キー `sozai-gacha-v2`）

## 本番素材への差し替え
`items.js` の各アイテムに `img: "images/apple.png"` を追加すると、`art` より優先して表示されます。
外部素材を使うときは `credit: { author: "Kenney", license: "CC0", url: "https://..." }` も付けると、詳細とクレジット画面に表示されます。
素材ごとのライセンス・クレジットは別途管理すること（Kenney＝CC0、OpenMoji＝CC BY-SA など）。
