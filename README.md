# 素材ガチャクリッカー

タップでポイントを貯めてカプセルを引き、フリー素材（食べ物・動物・家具・食器・植物・乗り物・建物・自然・ファッション・道具・あそび・絵画・偉人）を集めるクリッカーゲーム。UR を全種そろえると、AI 画像を集める裏の「AIクリッカー」が解放される。
ビルド不要。`index.html` をスマホのブラウザで開けば動きます（将来 Capacitor などでアプリ化予定）。

## ファイル構成
- `index.html` … 画面
- `style.css` … 見た目
- `config.js` … バランス調整用の数値（排出率・倍率・自動クリック）
- `items.js` … 素材データ（全3025種：N1047 / R897 / SR576 / SR+236 / UR193 / LR76、13ジャンル。攻撃・防御つき）。`tools/build-assets.js` で自動生成
- `ai-items.js` … 裏のAIクリッカーの素材（全7454種：C4217 / B1442 / A954 / S666 / SS175）、`atlas.js` … まとめ画像の一覧。どちらも `tools/build-pdq.py` で自動生成
- `images/n` ドット絵 PNG、`images/r` イラスト（SVG・WebP）、`images/sr` 写真（SR・SR+ 240px、UR・LR 320px JPEG）、`images/atlas` パブリックドメインQ の素材を10×10 にまとめた画像（n＝ドット絵 80px、m＝表の素材 128px、a＝AI画像 128px、WebP）。カードの `sp: [まとめ画像の番号, マス]`
- `tools/asset-list.js` … N・R の素材一覧、`tools/photo-list.json` … SR・SR+・UR の写真と絵画の一覧（`rank` に `'SR+'` / `'UR'` / `'LR'`、省略で SR）、`tools/gld_fetch.py` … Google Landmarks の画像を1枚ずつ取得（ここを編集して作り直す）
- `tools/pdq-select.py` … パブリックドメインQ の一覧ページから集めた投稿（タイトル・タグ・サムネイル）から、表の素材（`tools/pdq-list.json`）と AI 画像（`tools/ai-list.json`・ランク名は `tools/ai-ranks.json`）を選ぶ。`tools/build-pdq.py <サムネイルのキャッシュ>` でまとめ画像を作る（そのあと `tools/build-assets.js`）
- `LICENSES.md` … 素材のクレジットとライセンス
- `game.js` … ゲームロジック（ガチャ・図鑑・メニュー）
- `battle.js` … デッキ作成と CPU 対戦
- `tools/build-artifact.py` … 公開用の1ファイル版を作る（images/n・r・sr の画像は埋め込み。まとめ画像は公開ページのアセットに上げ、その URL の JSON を第3引数で渡す）

## 画面（スマホアプリ専用・縦画面）
- 上：ポイント／クリック合計／倍率／図鑑のステータスバー（大きい数は 万・億・兆・京・垓 で短く表示）
- ガチャ：中央に出てきたカード、親指の届く下部に大きなタップボタン（指を置いた瞬間に反応・連打/複数指OK、+ポイントが浮かぶ）。AIクリッカー解放後はタップボタンの上に表／裏の切り替えボタン
- 図鑑：ランクタブ＋ジャンルチップで絞り込み。「ランク×ジャンル」（例：N・動物）ごとに見出しと n/m を表示。新規入手があるとタブバーに赤丸。AIクリッカー解放後は上に「素材図鑑／AI図鑑」の切り替え（AI図鑑は「すべて」なし、持っていないカードは絵を読み込まない）
- メニュー：あそびかた・記録・クレジット・リセット
- デッキ：持っているカードから30枚を選ぶ（おまかせ・ぜんぶ外す）。枚数制限をこえるカードは押せない
- 対戦：CPU と対戦。上が CPU の場、下が自分の場と手札。カードを押して出す・攻撃・表示変更
- 下：タブバー（ガチャ／図鑑／デッキ／対戦／メニュー）。ノッチ・ホームバーの safe-area に対応
- PC・横向きは想定しない（アプリ化時は縦画面固定にする）

## 仕様
- **素材**：すべて実在のフリー素材（詳しくは LICENSES.md）
  - N ドット絵：Streamline Pixel（CC BY 4.0）・pixelarticons（MIT）を色付けしたもの、Twemoji（CC BY 4.0）を18マスにドット化したもの
  - R イラスト：Twemoji（CC BY 4.0）・Microsoft Fluent Emoji 3D（MIT）
  - UR 名所・名画：有名な建物＝Google Landmarks Dataset v2（Wikimedia Commons の写真。CC BY / CC0 など写真ごと）、有名な乗り物＝国立航空宇宙博物館（CC0）、絵画＝広重・北斎・レンブラント・ゴッホなど（Cooper Hewitt・スミソニアン・アメリカ美術館、CC0）
  - パブリックドメインQ（パブリックドメイン・CC0）の追加分 2060種：N＝フリーイラストを20マスにドット化、R＝フリーイラスト、SR・SR+＝フリー写真（人気の動物・乗り物・桜や紅葉などは SR+）、UR＝世界遺産の写真と名画（北斎・広重・国芳・芳年・川瀬巴水・吉田博・小原古邨・横山大観・モネ・ゴッホ・クリムトなど）、LR＝偉人24人（聖徳太子・菅原道真・平将門・清少納言・加藤清正・斎藤道三・柴田勝家・今川義元・ジャンヌ・ダルク・ナポレオン・マリー・アントワネット・ルイ14世・エリザベス1世・モーツァルト・ブラームス・ダーウィン・ノーベル・ピカソ・ケネディ・ペリー・孔子・ソクラテス・アリストテレス・曹操）
    - 実在の人の写真は入れない（LR の偉人だけ）。人物タグ・題名の言葉で除き、背景・パターン・枠などの素材も除く。AI 画像（タグ「フリーAI画像」「AI」）は裏のAIクリッカーへ
    - 一覧ページ（`/tag/<タグ>/page/N/`、1ページ18件）にタイトル・タグ・サムネイルがそろっているので、個別ページは開かない。サムネイルも元ページを Referer にしないと取れない
  - LR 偉人：国立肖像画美術館（National Portrait Gallery、CC0）の偉人36人の写真・肖像画（リンカーン・ワシントン・フランクリン・エジソン・アインシュタイン・グラハム・ベル・ライト・ポー・トウェインなど）と、パブリックドメインQ（パブリックドメイン）の日本の偉人16人（坂本龍馬・高杉晋作・木戸孝允・伊藤博文・板垣退助・山縣有朋・中岡慎太郎・夏目漱石・野口英世・渋沢栄一・陸奥宗光の写真、織田信長・豊臣秀吉・上杉謙信・明智光秀・源義経と弁慶の肖像画・浮世絵）。ドット・イラストはなし。カードは黒と金
    - パブリックドメインQ の画像は元ページを Referer にしないと取れない。使うのはページのプレビュー画像（フルサイズはクイズ回答が必要なので使わない）
  - SR+ 人気・貴重：SR の写真のうち人気の動物（パンダ・ライオンなど）、人気の乗り物（スポーツカー・こうそくれっしゃなど）、貴重品（銀器・アンティークの時計や椅子）。カードは金と赤
  - SR 写真：Smithsonian Open Access（CC0。動物＝国立動物園、家具・食器＝クーパー・ヒューイット、飛行機・宇宙船＝国立航空宇宙博物館）、Fruits-360（MIT。果物・野菜）、Open Images Dataset（CC BY 2.0。植物・乗り物。写真ごとに撮影者を表記）
- **ランク**：N＝ドット絵、R＝イラスト、SR＝写真、SR+＝人気・貴重な写真、UR＝有名な建物・乗り物・名画、LR＝偉人。排出率 57/27/8/5/2/1%。種類数は N＞R＞SR＞SR+＞UR＞LR
  - LR は UR を全種そろえると解放（それまで LR の1%は N になる）。解放時にガチャ画面でお知らせ、図鑑の LR 見出しに解放条件を表示
  - ダブったときは30%（`NEW_BIAS`）で同じランクのまだ持っていないカードに変わる（種類が多いので最後の数枚が出ないのを防ぐ）
- **ポイント**：1タップで「倍率」分のポイント。カプセル1個の値段は `4 × (引いた回数+1)^1.8 × 1.00042^引いた回数`（目安：5タップ/秒で自動クリック解放まで約4分、UR コンプ（LR・AIクリッカー解放）まで約45分、全3025種コンプまで約1.5〜3時間）
- **倍率**：`(1 + N種類数×0.5) × (1 + R種類数×0.05) × (1 + SR種類数×0.05) × (1 + SR+種類数×0.05) × (1 + UR種類数×0.2) × (1 + LR種類数×0.3)` × コンプボーナス を切り捨て
- **ジャンル別コンプボーナス**：「ランク×ジャンル」（約40区分）を全種そろえるごとに倍率×1.03（`GENRE_BONUS`）
- **ランク別コンプボーナス**：N を全種そろえると倍率×2、R は×2、SR は×2、SR+ は×3、UR は×4、LR は×5
- **自動クリック**：新規カード（種類数）が20種に達したら解放。間隔は 1000ms から、1種増えるごとに ×0.9（最短50ms）
  - 自動クリックにも倍率が乗る。タップ数には数えない
  - ガチャ画面を開いているときだけ動く（図鑑・デッキ・対戦・メニューに移ったとき、アプリやブラウザのタブを切り替えて画面が見えないときは止まる）
- **攻撃・防御**（今後の対戦機能用）：各カードに攻撃・防御（それぞれ1〜20）。合計は N 6〜15、R 14〜25、SR 22〜30、SR+ 31〜35、UR 36〜40、LR 38〜40 でランクが高いほど強い。攻撃の上限は N 10・R 15・SR 20・SR+ 18・UR 20・LR 20（`ATK_MAX`）
  - `tools/build-assets.js` が ID から決まった値を自動で割り振る（毎回同じ）。動物・乗り物・あそびは攻め寄り、植物・家具・建物は守り寄り
  - `tools/asset-list.js` / `photo-list.json` の行に `atk` と `def` を書けば手動で決められる（範囲外はビルドでエラー）
  - カードの名前の下に「攻○ 防○」、図鑑の詳細に攻撃・防御・合計を表示
- **デッキ**（`CONFIG.DECK`）：30枚。LR 1枚まで、UR 2枚まで、SR と SR+ は合わせて5枚まで、R 10枚まで、同じカードは1枚だけ（`COPY`）。`st.deck` に保存
- **対戦**（battle.js）
  - 最初に5枚引き、コイントスで先攻・後攻。自分のターンのはじめに1枚引く（山札が引けなければ負け）
  - 1ターンに出せるのは1枚。場は4枚まで。出すときに表/裏・縦（攻撃）/横（守備）を選ぶ。裏は相手から見えない
  - 出すときに場のカードを使用不可にする枚数（`CONFIG.TRIBUTE`）：N 0・R 1・SR/SR+ 2・UR/LR 3
  - 先攻の1ターン目は攻撃できない。縦のカードで攻撃し、各カード1ターン1回
  - 縦の相手：攻撃同士を比べ、負けたほうが使用不可。差分は負けた側のライフから引く（攻撃側が負けたら自分のライフが減る）。同じなら両方使用不可
  - 横の相手：攻撃対守備。負けたほうが使用不可で、ライフは減らない。同じならどちらも残る
  - 相手の場が空なら攻撃ポイントがそのままダメージ。ライフ50（`BATTLE_LIFE`）が先に0になったほうの負け
  - 置いたターンと攻撃後以外なら1ターン1回だけ縦横を切り替え可（裏なら表になる）
  - CPU のデッキはあなたのデッキと同じランク構成で全カードからランダム。CPU は裏のカードを見ず、数値9とみなして勝てる相手だけ攻撃する
  - 勝敗はメニューの記録に表示
- **裏：AIクリッカー**（`CONFIG.AI`、`ai-items.js`）：UR を全種そろえる（LR 解放）と同時に解放。ガチャ画面のボタンで表と裏を切り替え（`st.mode`）、見た目は暗いネオン
  - 素材はパブリックドメインQ のフリーAI画像（CC0）7454種。水着・暴力・事故などの画像は除外。AI で作った人物の写真・イラストは入れてよい
  - ランクは題材ごと：C AIポートレート（人物の写真）・B AIワールド（風景・乗り物・食べ物など）・A AIアニマル・S AIキャラクター（人物のイラスト）・SS AIファンタジー（ドラゴン・魔法・宇宙・ロボットなど）。排出率 58/17/12/10/3%、種類数は C＞B＞A＞S＞SS。ジャンルは題材の中の分類（女性・男性・子供・ふたり以上、犬・猫・鳥など）
  - ポイント・図鑑・自動クリック・記録は表とは別（`st.ai`）。値段は `3 × (引いた回数+1)^2 × 1.00085^引いた回数`、倍率は各ランク1種ごと +0.1（SS は +0.5）の掛け算、ランク別コンプ C×2・B×2・A×3・S×4・SS×5、ランク×ジャンルのコンプごとに×1.1、ダブりは30%で未入手に変わる。自動クリックは10種で解放（500ms から1種ごとに×0.97、最短50ms）。目安：自動クリック解放まで約3分、全種コンプまで約2〜3時間
  - S・SS を新しく引くと全画面演出（S はシアンのネオン、SS は虹色のネオン）
  - 攻撃・防御はなく、デッキ・対戦には使わない
- **クリック合計**：これまでのクリック（タップ＋自動クリック）で稼いだポイントの合計。ステータスバーに常に表示、内訳はメニューの記録に
- **全種コンプ記録**：最初のタップからコンプまでの時間・タップ数・回数を表示
- **レア演出**：SR・SR+・UR・LR を新しく引いたときだけ全画面演出（ダブりは出ない）（フラッシュ→カードが回転しながら表に→ランク表示・光の筋・キラキラ・光の反射。UR は虹色と揺れ、スマホは振動）。演出中はタップも自動クリックも一時停止し、演出が終わるまで画面を押しても反応しない（SR 2.6秒・SR+ 3秒・UR 3.8秒・LR 4.6秒。LR は黒と金）。終わると「タップで再開」が出て、タップで閉じてクリック再開。ダブりの SR 以上はガチャ画面のカードが光るだけ
- **図鑑の詳細**：入手済みカードを押すと拡大表示＋所持数・素材の出典
- **クレジット画面**：素材の配布元ごとに作者・ライセンス・改変内容・該当素材を一覧
- **セーブ**：localStorage（キー `sozai-gacha-v3`。素材の種類数が変わると全種コンプ記録は取り直し）

## 素材の入れ替え・追加
1. 素材の npm パッケージを取得して展開（`npm pack <名前>` → `tar xzf`。展開先のフォルダ名は `tools/build-assets.js` 冒頭を参照）
2. `tools/asset-list.js`（N・R）または `tools/photo-list.json`（SR 写真）に行を足す
   - N は `icon` と `fill`（Streamline/pixelarticons）か `src: 'twp'` と絵文字の `code`（Twemoji をドット化）、R は絵文字の `code`、SR は Smithsonian の画像ID・Open Images の ImageID（`media`）か Fruits-360 のフォルダ名
3. 写真を変えたら `python3 tools/build-photos.py <キャッシュ> <Fruits-360のclone>`（Fruits-360 は `git clone --filter=blob:none --no-checkout` で十分）
4. `node tools/build-assets.js <展開したディレクトリ>` で `items.js` と `images/` を作り直す（名前・ID の重複はエラーになる）
5. 新しい配布元を使ったら `CREDIT` と LICENSES.md にも追記する

Kenney（kenney.nl、CC0）の素材も使える。zip をダウンロードして `images/` に置き、`items.js` の該当アイテムに `img` と `credit` を書けばよい（CC0 なので表記は任意だが、クレジットには載せる）
